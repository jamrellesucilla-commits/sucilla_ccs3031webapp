# CCS website (Vue + Vite)

## Run
    npm install
    npm run dev

## Images
Replace the placeholder files in `images/` with your real ones, SAME file names:
logo-ccs.png, cs.png, itso.png, midas.png, lisso.png, ting.png, ccs.jpg

## Deploy
Push to GitHub, import the repo in Vercel (Vite preset), then every `git push` redeploys.
